# Тестовые фикстуры и подмены

Повторно используемые данные и реализации портов только для тестов.

## Содержимое

- `fixtures.ts` — модели товаров, корзины, заказов, пользователя, фиксированное время и тестовое хеширование.
- `unit-of-work.ts` — TestUnitOfWork с подменяемыми методами репозиториев и счётчиками операций.

## Правила и ограничения

- Не импортируйте этот каталог в production-код.
- Фикстуры должны быть небольшими, детерминированными и независимыми от окружения и рабочей БД.
- Настраивайте только ожидаемые вызовы; неожиданный метод репозитория должен приводить к ошибке теста.
- TestUnitOfWork проверяет оркестрацию, но не реализует реальные откаты, блокировки или изоляцию PostgreSQL.
- Изменение общего объекта в одном тесте не должно менять данные другого: используйте фабрики и отдельные экземпляры.
- Тестовый хешер и токены не являются security-адаптерами для приложения.

## Проверки

Проверяйте helpers тестами сервисов; атомарность и конкурентный доступ подтверждайте отдельно интеграционными тестами.
