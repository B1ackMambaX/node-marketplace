# Prisma: схема и данные

Описание структуры PostgreSQL, история изменений схемы и демонстрационные данные приложения.

## Содержимое

- `schema.prisma` — модели, связи и перечисления ORM.
- `seed.ts` — повторно запускаемое наполнение демонстрационными аккаунтами, категориями и товарами.
- [migrations](migrations/README.md) — SQL-миграции; конфигурация CLI расположена в корневом `prisma.config.ts`.

## Правила и ограничения

- Согласовывайте изменения схемы с доменными моделями, портами и инфраструктурными репозиториями.
- Создавайте новую миграцию для изменения структуры БД; не переписывайте применённые миграции.
- Не редактируйте сгенерированный Prisma Client: он создаётся в `src/generated/prisma` командой `bun run db:generate`.
- Seed требует `DATABASE_URL` и `SEED_PASSWORD` длиной не менее 12 символов; повторный запуск не должен сбрасывать существующие пароли, цены и остатки.
- Прямое использование Prisma в seed допустимо как часть служебного скрипта, но не переносится в прикладные сервисы.

## Проверки

После изменения схемы: `bun run db:migrate --name <название>`, `bun run db:generate` и затронутые интеграционные тесты. Для существующих миграций: `bun run db:deploy`; демонстрационные данные: `bun run db:seed`.
