# Начальная миграция

Исходная версия PostgreSQL-схемы маркетплейса.

## Содержимое

- `migration.sql` создаёт перечисления, таблицы, индексы и внешние ключи для пользователей, сессий, товаров, SKU, остатков, модерации, корзины и заказов.
- CHECK-ограничения защищают цены, количества, сумму заказа и соотношение физического остатка с резервом.
- Частичный уникальный индекс разрешает только одну заявку `PENDING` на товар; уникальные ключи защищают позиции корзины и идемпотентность заказа.

## Правила и ограничения

- Считайте эту миграцию неизменяемой после применения; исправления оформляйте в новом соседнем каталоге миграций.
- Не добавляйте сюда актуальные бизнес-правила сервисов или демонстрационные данные.
- Не удаляйте ограничения на резерв, денежные суммы и уникальность при последующих изменениях схемы.
- README описывает миграцию, но не участвует в её исполнении.

## Проверки

Применяйте через `bun run db:deploy` из корня. Проверяйте на отдельной PostgreSQL-БД, затем запускайте интеграционные тесты.
