# Регистрация маршрутов

Связывание HTTP-методов и URL с контроллерами и middleware.

## Содержимое

- `*.routes.ts` — маршруты соответствующих частей API.
- `index.ts` — создание контроллеров и объединение маршрутов API; внешний префикс `/api/v1` добавляет `../app.ts`.

## Правила и ограничения

- Маршруты содержат только регистрацию обработчиков и middleware; бизнес-логика, SQL и inline-сценарии запрещены.
- Передавайте готовые контроллеры и middleware; конкретные инфраструктурные адаптеры сюда не импортируются.
- Защищённые операции должны сохранять authenticate и проверку ролей; публичный каталог и чтение категорий остаются публичными.
- При изменении метода/пути обновляйте OpenAPI и HTTP-тесты.
- Используйте именованные обработчики вместо циклов, которые скрывают различия между разными операциями.

## Проверки

Проверяйте маршруты, middleware и отсутствие конфликтов путей в соответствующих интеграционных сценариях.
