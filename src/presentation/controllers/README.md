# HTTP-контроллеры

Обработчики отдельных HTTP-операций API.

## Содержимое

- `*.controller.ts` — авторизация, категории, товары, SKU, модерация, каталог, корзина, заказы и системные проверки.
- Обработчики передаются маршрутам; зависимости приходят через конструкторы.

## Правила и ограничения

- Один обработчик разбирает вход через схему, получает пользователя/параметры, вызывает сервис и формирует статус/ответ.
- Не выполняйте SQL, не обращайтесь к Prisma и не создавайте адаптеры.
- Не реализуйте здесь резервирование, расчёт цены, проверки бизнес-статусов или транзакционные сценарии.
- Используйте `currentUser` и `pathId` вместо непроверенных утверждений о наличии пользователя и корректности ID.
- Передавайте ошибки общему middleware; не дублируйте преобразование ошибок во всех обработчиках.

## Проверки

Проверяйте соответствующие HTTP-сценарии через Supertest, включая статусы, валидацию, роли и принадлежность объектов.
