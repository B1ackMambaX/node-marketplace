# HTTP-слой

Express-приложение и перевод между HTTP-контрактами и прикладными сценариями.

## Содержимое

- `app.ts` — создание HTTP-приложения из переданных зависимостей.
- `request.ts` — получение UUID-параметров и текущего пользователя.
- [controllers](controllers/README.md), [routes](routes/README.md), [schemas](schemas/README.md), [middleware](middleware/README.md), [docs](docs/README.md), [types](types/README.md) — компоненты HTTP-слоя.

## Правила и ограничения

- Обращайтесь к сервисам application и моделям domain; прямые импорты инфраструктуры, Prisma и generated-клиента запрещены.
- Не создавайте подключения к БД при сборке HTTP-приложения: необходимые возможности передаются зависимостями.
- Форма запроса проверяется здесь, бизнес-решение — в сервисе, хранение — в репозитории.
- Сохраняйте `/api/v1`, формат ошибок, пагинацию и соответствие OpenAPI реальным маршрутам.
- Сквозные middleware подключаются централизованно; обработчик ошибок должен оставаться после маршрутов.

## Проверки

При изменении HTTP-контракта обновляйте схемы, OpenAPI и интеграционные тесты. Границы проверяются ESLint и архитектурным тестом.

Общие правила: [AGENTS.md](../../AGENTS.md). Родительский каталог: [README.md](../README.md).
