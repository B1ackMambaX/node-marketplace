# HTTP middleware

Сквозные проверки запросов и единое преобразование ошибок в HTTP-ответы.

## Содержимое

- `authentication.ts` — извлечение Bearer-токена, обращение к AuthService и ограничение ролей.
- `error-handler.ts` — перевод Zod/ApplicationError и ошибок парсинга тела в JSON-ответ.

## Правила и ограничения

- Не проверяйте JWT напрямую библиотекой jose и не читайте таблицы пользователей: используйте AuthService.
- Middleware проверяет аутентификацию и роль; принадлежность бизнес-объекта проверяет соответствующий сервис.
- Не допускайте HTTP-статусы в доменных ошибках: преобразование ErrorKind находится здесь.
- Не включайте stack trace, ошибки ORM, пароли или токены в ответ клиенту.
- Не поглощайте неизвестные ошибки и не продолжайте обработку после сформированного ошибочного ответа.

## Проверки

Проверяйте отсутствующий/неверный токен, недостаточную роль, ошибки валидации, некорректный JSON и внутренние ошибки через HTTP-тесты.
