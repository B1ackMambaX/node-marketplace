# Расширения типов Express

Типизация дополнительного контекста HTTP-запросов.

## Содержимое

- `express.d.ts` расширяет Express Request необязательным полем `user: UserProfile`.

## Правила и ограничения

- Каталог содержит декларации типов, а не runtime-обработчики или бизнес-модели.
- Не дублируйте UserProfile: используйте доменную модель.
- `user` остаётся необязательным, поскольку часть маршрутов публичная и аутентификация может ещё не выполняться.
- Получайте пользователя через проверяющий helper; наличие декларации не заменяет аутентификацию.
- Не добавляйте Prisma Client, transaction client или секреты в контекст Express.

## Проверки

Проверяйте совместимость деклараций командой `bun run typecheck` и затронутыми HTTP-сценариями.
