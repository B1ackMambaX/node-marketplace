# Прикладной слой

Реализация пользовательских сценариев и независимые контракты взаимодействия с внешними механизмами.

## Содержимое

- `dto.ts` — входные структуры, фильтры и типы пагинации.
- [services](services/README.md) — сценарии и границы транзакций.
- [contracts](contracts/README.md) — интерфейсы репозиториев, безопасности, часов и доступности БД.
- [mappers](mappers/README.md) — явное преобразование результатов для потребителя.

## Правила и ограничения

- Зависите только от собственного кода и `domain`; не импортируйте HTTP, Prisma, generated-клиент, инфраструктуру или платформенные API.
- Сценарии получают зависимости через интерфейсы и конструкторы; не создавайте конкретные адаптеры здесь.
- Прикладной DTO не должен содержать `Request`, `Response`, ORM where/include или transaction client.
- Задавайте границы атомарной операции через RepositoryContext; не реализуйте здесь изоляцию и повторы Prisma.
- Ошибки остаются независимыми от HTTP; преобразование в статус и JSON выполняет presentation.

## Проверки

Основная проверка — тесты сервисов с подменёнными портами: `bun test tests/services.test.ts tests/architecture.test.ts`; дополнительно typecheck и ESLint.
