# Прикладные сервисы

Сценарии авторизации, управления категориями/товарами/SKU, модерации, каталога, корзины и заказов.

## Содержимое

- `*.service.ts` — сервисы соответствующих сценариев.
- `access.ts` — получение принадлежащих продавцу объектов и проверка наличия связанных сущностей.
- `index.ts` — создание сервисов из переданных контрактов, без выбора конкретных адаптеров.

## Правила и ограничения

- Сервисы не знают Express, Zod, Prisma, конфигурацию окружения или реализацию JWT.
- Проверяйте владельца и бизнес-состояние до записи; используйте доменные правила и семантические ошибки.
- Оформление заказа, изменение резервов, создание снимков и очистка корзины выполняются в одной транзакции.
- Решение модерации и статус товара изменяются атомарно; повторные операции не должны повторять финансовые или складские эффекты.
- Callback транзакции может быть выполнен повторно: не помещайте в него необратимые внешние действия.
- Разбивайте сложный сценарий на именованные шаги; не объединяйте разные операции в один обработчик с проверкой HTTP-метода.

## Проверки

Запускайте `bun test tests/services.test.ts`; транзакционные и конкурентные изменения дополнительно проверяйте интеграционными тестами с PostgreSQL.
