# Мапперы прикладных результатов

Преобразование внутренних моделей в данные, которые можно вернуть потребителю сценария.

## Содержимое

- `catalog.mapper.ts` — публичный товар и доступный остаток.
- `cart.mapper.ts` — представление корзины с актуальными ценами и доступностью.
- `order.mapper.ts` — заказ без внутренних полей идемпотентности.

## Правила и ограничения

- Мапперы не выполняют I/O, SQL и HTTP-операции, не меняют исходные модели.
- Разрешены собственные функции, DTO и доменные модели/правила; конкретные адаптеры запрещены.
- Для публичных данных используйте явный перечень полей; не раскрывайте внутреннюю модель через безусловный spread.
- Сохраняйте денежные суммы в копейках и используйте единые доменные правила вычисления доступного остатка.
- Бизнес-переходы и авторизация принадлежат сервисам, а формат статусов HTTP — presentation.

## Проверки

Проверяйте форму ответа и отсутствие закрытых полей в тестах сервисов; изменение публичного результата также отражайте в OpenAPI и HTTP-тестах.
