# Домен

Независимая модель маркетплейса и правила, которые не привязаны к транспорту или базе данных.

## Содержимое

- `models.ts` — модели пользователей, товаров, SKU, модерации, корзины и заказов.
- `constants.ts` — бизнес-лимиты и сроки действия токенов.
- `product-rules.ts` и `order-rules.ts` — доступность товара, расчёт сумм и переходы статусов.
- `errors.ts` — категории и коды ошибок приложения без HTTP-статусов.

## Правила и ограничения

- Импортируйте только код этого слоя; Express, Prisma, Zod, платформенные API и другие слои запрещены.
- Правила должны быть детерминированными: без чтения окружения, SQL, запросов по сети и скрытых побочных эффектов.
- При необходимости времени принимайте готовое значение от вызывающего сервиса. Не импортируйте прикладной Clock и не обращайтесь к системным часам из доменного правила.
- Все деньги выражаются целыми копейками; придерживайтесь существующих статусов и инвариантов остатков.
- Не используйте Prisma-типы или HTTP DTO как доменные модели.

## Проверки

Изменения правил сопровождайте сценарными unit-тестами. Запуск: `bun test tests/order-rules.test.ts tests/services.test.ts tests/architecture.test.ts`.
