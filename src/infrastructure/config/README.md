# Конфигурация окружения

Чтение и проверка переменных окружения для инфраструктурных адаптеров.

## Содержимое

- `environment.ts` — обязательный `DATABASE_URL` и преобразование `JWT_SECRET` в байты.
- Пример значений хранится в корневом `.env.example`; Prisma CLI настраивается отдельно через `prisma.config.ts`.

## Правила и ограничения

- Не храните здесь реальные пароли, строки подключения или секреты по умолчанию.
- Отсутствующая обязательная настройка должна приводить к понятной ошибке конфигурации.
- `JWT_SECRET` должен содержать не менее 32 символов; не выводите его в логи.
- Новые параметры документируйте в `.env.example` и корневом README.
- Не переносите чтение `process.env` в домен или прикладные сервисы; передавайте готовые значения через зависимости.

## Проверки

Проверяйте поведение с отсутствующими и некорректными значениями без публикации содержимого локального `.env`.

Общие правила: [AGENTS.md](../../../AGENTS.md). Родительский каталог: [README.md](../README.md).
