# Адаптеры безопасности

Конкретные механизмы хеширования и выпуска/проверки токенов.

## Содержимое

- `password-hasher.ts` — реализация PasswordHasher на `Bun.password` с Argon2id.
- `token-provider.ts` — JWT через jose, криптографически случайные refresh-токены и SHA-256-хеширование.

## Правила и ограничения

- Реализуйте контракты application; не добавляйте сюда HTTP middleware или запросы к репозиториям.
- Не храните пароли и refresh-токены открытым текстом и не выводите секреты или токены в логи.
- При проверке JWT сохраняйте ограничения алгоритма, issuer, audience и срока действия.
- Не заменяйте криптографическую генерацию на `Math.random`; секрет поступает через конструктор.
- Ротация и отзыв сессий выполняются AuthService через репозитории; адаптер отвечает за криптографические операции.

## Проверки

Проверяйте вход, недействительный access, истёкший refresh, ротацию и logout; для сервисов используйте подменяемые security-порты.
