# Подключение и транзакции БД

Общая инфраструктура работы с PostgreSQL через Prisma.

## Содержимое

- `client.ts` — Prisma Client с PostgreSQL-адаптером и тип клиента репозиториев.
- `repository-context.ts` — PrismaRepositoryContext: обычное чтение, Serializable-транзакции и до трёх повторов после первой попытки при конфликте P2034.
- `errors.ts` — преобразование известных ошибок Prisma в ошибки приложения.
- `readiness.ts` — проверка подключения через `SELECT 1`.

## Правила и ограничения

- Передавайте один transaction client всем репозиториям внутри атомарного сценария.
- Не открывайте новые независимые соединения или вложенные транзакции из репозиториев.
- Повторяйте только предусмотренные конфликты сериализации и сохраняйте ограничение числа попыток.
- Ошибки ORM преобразуются здесь; presentation не должен импортировать Prisma для их распознавания.
- Бизнес-сценарий определяет, какие изменения атомарны; этот каталог определяет механизм исполнения, таймауты и изоляцию.

## Проверки

Изменения транзакций проверяйте на PostgreSQL: конкурентное оформление, резерв последней единицы, откат, повторная отмена и завершение заказа.
