# Prisma-репозитории

Реализации методов чтения и записи сущностей на PostgreSQL.

## Содержимое

- `*.repository.ts` — реализации портов пользователей, сессий, категорий, товаров, SKU, остатков, модерации, каталога, корзины и заказов.
- `selections.ts` — общие Prisma select/include.
- `index.ts` — создание всех репозиториев на переданном клиенте БД.

## Правила и ограничения

- Принимайте клиент через конструктор; не подменяйте его глобальным Prisma Client внутри операции.
- Сохраняйте интерфейсы application-портов и не передавайте ORM-типы наружу.
- Не определяйте здесь право публикации, отмены или смены статуса; эти решения принимает сервис.
- SQL должен быть параметризованным; не подставляйте пользовательские значения в текст запроса.
- Операции резерва/освобождения/списания используют атомарные изменения и проверки количества изменённых записей.
- Учитывайте мягкое удаление и ограничения владельца в соответствующих методах; не удаляйте данные истории заказов.

## Проверки

Проверяйте реализации typecheck и интеграционными тестами; при изменении сортировки или выборки сохраняйте контракт каталога и публичные поля.
