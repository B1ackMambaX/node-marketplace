# Инфраструктура

Конкретные реализации внешних механизмов, описанных прикладными контрактами.

## Содержимое

- [config](config/README.md) — чтение окружения.
- [database](database/README.md) — Prisma Client, RepositoryContext, готовность БД и перевод ошибок.
- [repositories](repositories/README.md) — чтение и запись сущностей.
- [security](security/README.md) — Argon2id, JWT и криптографические операции.

## Правила и ограничения

- Разрешены контракты application, доменные модели, Prisma/generated-клиент и необходимые внешние библиотеки.
- Не импортируйте presentation или Express и не формируйте HTTP-ответы.
- Адаптеры реализуют заданные интерфейсы; бизнес-решения и границы сценариев остаются в сервисах.
- Конкретные реализации выбираются в `src/dependencies.ts`, а не внутри прикладного кода.
- Не смешивайте параметры окружения, SQL и security-операции в одном адаптере.

## Проверки

Проверяйте интерфейсы через typecheck и границы через ESLint; поведение БД требует интеграционных тестов, криптографические изменения — проверок авторизации.

Общие правила: [AGENTS.md](../../AGENTS.md). Родительский каталог: [README.md](../README.md).
